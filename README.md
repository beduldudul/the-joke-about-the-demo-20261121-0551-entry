Entry for the make.fun bounty
[the-joke-about-the-demo-20261121-0551](https://make.fun/bounty/the-joke-about-the-demo-20261121-0551).

The program writes one short text to `/output/entry.txt`: a one-line joke
about working beside AI coding agents. The joke: an agent rehearses the
demo twelve times, then walks on stage and demos a feature it invented on
the spot — the hallucination every developer who has watched an agent
present recognises at once.

## Run

```sh
node main.ts
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
